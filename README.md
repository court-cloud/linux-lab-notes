
# Linux Labs & Cloud Engineering Home Lab

## About This Repository

This repository documents my hands-on Linux and cloud engineering training through a personal home lab.

I use an Ubuntu Server environment to practice Linux administration, networking, SSH, Git, automation, and infrastructure concepts. My goal is to turn structured training into practical, repeatable skills that can be demonstrated through real projects.

## Home Lab Environment

- **Host:** Windows PC
- **Virtualization:** Oracle VirtualBox
- **Server OS:** Ubuntu Server
- **Server Hostname:** tech-cloud
- **Networking:** VirtualBox NAT
- **Remote Administration:** SSH
- **Version Control:** Git
- **Repository Hosting:** GitHub

## Current Focus

- Linux system administration
- File and directory management
- Users, groups, and permissions
- Networking and troubleshooting
- SSH and remote administration
- Bash scripting and automation
- Git and GitHub
- Docker and containerization
- Cloud engineering fundamentals
