# Linux Fundamentals

## Objective

Build foundational Linux command-line skills through hands-on practice in an Ubuntu Server environment.

## Environment

- **Operating System:** Ubuntu Server
- **Server:** `tech-cloud`
- **Access:** SSH from Windows PowerShell
- **Shell:** Bash

## Skills Practiced

- Navigating the Linux filesystem
- Creating and managing files and directories
- Viewing and searching file contents
- Understanding absolute and relative paths
- Using common Linux command-line utilities
- Working with command output
